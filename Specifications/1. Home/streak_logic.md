# Streak Logic

## Definitions
- **Active Streak Count:** consecutive days with all 5 prayers complete. Shown on leaderboard and My Profile. Resets to 0 on any miss.
- **Total Streak Score:** cumulative lifetime streak units. Never resets. Used for SS Coins and All Time leaderboard.

## Core Rules
- 5 green ticks in one day = 1 streak unit
- Days must be consecutive
- Missing any prayer = Active Streak Count resets to 0
- Total Streak Score never resets

## Streak Revive
- Available for 24 hours after losing streak
- Popup shown every app open within 24 hour window
- User can dismiss popup
- After 24 hours: Revive expires permanently for that miss
- **Core:** 1 Revive/calendar month, costs 50 SS Coins, restores count
- **Premium:** 4 Revives/calendar month, free, restores count
