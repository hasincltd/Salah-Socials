# SS Coins Logic

## Earning
- Total Streak Score = SS Coin Balance (1:5 ratio)
- Spending never reduces Total Streak Score

## Spending
- Purchases deduct from SS Coin Balance only
- Balance updates in real time

## Display
- Icon: two gold coins horizontally stacked, SS engraved, balance beside it
- Position: top left, below Bell icon
- Screens: Home, Community, My Profile, Events
- Updates in real time

## SS Coin Balance Logic
- New user: Total Streak Score = 0, SS Coin Balance = 0
- Example: 243 Total Streak Score → 1215 SS Coin Balance
- User spends 300 coins → SS Coin Balance = 915, Total Streak Score stays 243
