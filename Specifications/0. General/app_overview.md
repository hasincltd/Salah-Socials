# Salah Socials — App Overview

**Version:** 2.0  
**Platform:** iOS first, Android Phase 2  
**Target:** Sunni Muslims aged 16-40, UK-first launch  
**Stack:** Flutter, Firebase, Google Maps SDK, Aladhan API

## Core Philosophy

- No judgement — home prayer and mosque prayer treated equally
- Celebration over guilt — reward progress, never shame misses
- Community first — social layer is central, not an afterthought
- Premium feels aspirational, not a paywall
