# Events Radius Filter Logic

## Location Controls
- Top of Events screen: "Current Location" pill and "Choose Address" dropdown
- Choose Address: postcode/address input → anchors event search radius
- Radius pills: 0.5mi / 2mi / 5mi / 10mi — default 2mi
- Changing radius or location refreshes event list immediately

## Sorting
- Events sorted by distance first, then date
- Empty state: "No events nearby — try expanding your radius"
