# Join Logic (Post-MVP)

## Free Event Flow
1. Tap Join
2. Registration popup — option to pre-fill with profile info
3. Confirmation screen with receipt and QR code
4. QR code saved to My Events
5. Return to Events screen

## Paid Event Flow
1. Tap Join
2. Registration popup — option to pre-fill with profile info
3. Payment popup or Apple Pay
4. Confirmation screen with receipt and QR code
5. QR code saved to My Events
6. Return to Events screen on OK

## My Events
- Icon in Events tab navigation header
- Stores all QR codes and event attendance history
- Shows upcoming events and past events
