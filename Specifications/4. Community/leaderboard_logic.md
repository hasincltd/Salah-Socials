# Leaderboard Logic

## Four Tabs
| Tab | Scope | Sorted By |
|---|---|---|
| Active | Friends only | Active Streak Count |
| All Time | Friends only | Total Streak Score |
| My Mosque | Friends + same mosque users | Active Streak Count |
| Top 100 | Country-based top 100 users | Active Streak Count |

## Profile Viewing from Leaderboard
- **Friends:** full profile — Avatar, Active Streak Count, SS Coin balance, Badges, Bio
- **Non-friends:** Username and Avatar only
  - Friend Request button shown, greyed until tapped
  - Tapped → turns gold, shows "Friend Request Sent"

## Top 100
- Based on user's registered country (UK used as default example)
- Top 100 by Active Streak Count across all app users in that country
- Non-friends shown at limited view (username + avatar only)
