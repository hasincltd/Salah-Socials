# Friend System Logic

## Friendship Rules
- Mutual — both users must accept before appearing as friends
- Friend count shown top right of Community tab
- Search icon left of Friends chip → opens search by username or QR scanner

## Friend Requests
- Stored at top of Bell icon notifications page
- Instagram-style format: avatar, username, Accept / Decline buttons

## Privacy
- Non-friends can see: username and avatar only on leaderboard
- Friends can see: full profile including streak, coins, badges, avatar
