# Settings Logic

## Access
- Gear icon top right of every screen
- Opens as a pushed route (full screen, back arrow to return)

## Settings Sections

### Account
- Edit username
- Edit display name
- Change profile picture
- Change password
- Delete account

### Location
- Home location (postcode input with pin-drop map)
- Reset to current GPS location

### Prayer Settings
- Calculation method (Muslim World League default)
- Madhab for Asr time (Hanafi / Shafi)

### Notifications
- Toggle each prayer notification on/off
- Adjust timing: at prayer time / 15 min before / 30 min before
- 15 minute warning on/off
- Community notifications on/off
- Streak notifications on/off
- Do Not Disturb hours (Fajr overrides DND with gentle sound only)

### Subscription
- Current tier shown
- Upgrade to Premium button
- Manage subscription

### Privacy
- Who can send friend requests: Everyone / Nobody
- Profile visibility: Public / Friends only
- Leaderboard opt-out toggle

### App
- App version
- Terms of Service
- Privacy Policy
- Contact Support
